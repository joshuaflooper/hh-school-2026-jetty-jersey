# Домашнее задание по Jetty + Jersey
## Что наделал?
 
Решил сделать бэкенд простенького чата. За одно потренировался с Hibernate, так как по нему не было домашки. Spring не использовал, всё ручками.

У меня 4 эндпоинта:
* GET из корня просто возвращает приветствие,
* GET из /messages/ возвращает список всех сообщений,
* POST в /messages/ создаёт новое сообщение (текст нужно передать в теле запроса через json по ключу "text"),
* GET из /messages/{id} возвращает сообщение с заданным id, если такое есть, иначе возвращает 404.

Есть ReaderInterceptor, который логирует заголовки и тело запросов в консоль через SLF4J. 
(Увидел варнинг при запуске Jetty, что SLF4J есть, а провайдеров нету — 
почитал в интернете, добавил простой провайдер с выводом в консоль).

**Тестовые запросы можно найти в `examples.http`!** 

Вроде всё рассказал.
